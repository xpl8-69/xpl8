# 0x69er-ctf

a web-based CTF with 7 zones. starts easy, gets nasty.
no handholding. figure it out.

---

## stack

- Node.js + Express
- clues are server-generated PNGs 
- flag only leaves the server when you earn it

---

## run it

```bash
npm install
node server.js
```

open `http://localhost:3000`
