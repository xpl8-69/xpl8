CHALLENGE 01 — "three parts, one word"  [50 pts / Easy]
  Category : Encoding / Crypto
  Answer   : GHOST
  Method   :
    The page source has four hex fragments as HTML comments:
      p1="5453"  p2="4F"  p3="48"  p4="47"
    Join them: 5453 4F 48 47
    Read each two hex digits as ASCII:
      54=T  53=S  4F=O  48=H  47=G
    Reverse the string: G H O S T  →  GHOST
  Hints    :
    Hint 1 (-10 pts): each operation's output feeds the next.
    Hint 2 (-15 pts): one operation is reversible by reading backwards.


CHALLENGE 02 — "noisy bits"  [75 pts / Easy]
  Category : XOR Cipher
  Answer   : CIPHER
  Method   :
    The clue gives an array of hex bytes and a key (_0x0A_ = 10):
      0x49 0x43 0x5A 0x42 0x4F 0x58
    XOR each with 10 (0x0A):
      0x49^0x0A = 0x43 = C
      0x43^0x0A = 0x49 = I
      0x5A^0x0A = 0x50 = P
      0x42^0x0A = 0x48 = H
      0x4F^0x0A = 0x45 = E
      0x58^0x0A = 0x52 = R
    Result: CIPHER
  Hints    :
    Hint 1 (-15 pts): something was applied to each byte.
    Hint 2 (-20 pts): XOR is self-inverse — knowing the key lets you undo it.
